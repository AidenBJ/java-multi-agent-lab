S4.2后台任务与定时调度

模块：scheduler

1. 这个模块解决了什么

慢操作不该阻塞主循环——丢后台虚拟线程；到点自动触发，不需要人推。

2. 机制

后台任务：BackgroundTaskManager——虚拟线程池 submit 立即返回 taskId，完成后查结果。
定时调度：CronScheduler——ScheduledExecutorService.scheduleAtFixedRate 到点自动跑。

5.5 核心类详解

SchedulerDemo（演示入口）

作用：启动调度器演示，展示后台任务和定时调度。

BackgroundTaskManager（后台任务管理器）

作用：管理后台任务，用虚拟线程执行。

方法：
方法作用输入输出
submit(Supplier task)提交后台任务任务任务 ID
status(String taskId)查询任务状态任务 ID状态
result(String taskId)查询任务结果任务 ID结果

CronScheduler（定时调度器）

作用：定时触发任务。

🚀 初学者快速上手

前置知识：理解"后台线程"和"定时任务"。
核心概念一句话：慢活丢后台不等，到点自动触发。
跑起来看：SchedulerDemo 后台任务立即返回，定时每 200ms 触发。

3. 运行命令

mvn -q -pl s42-scheduler exec:java "-Dexec.mainClass=com.example.agentlab.scheduler.SchedulerDemo"
