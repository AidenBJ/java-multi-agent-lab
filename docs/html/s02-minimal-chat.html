S0.2最小对话：命令行多轮 + 流式

模块：minimal-chat

1. 这个模块解决了什么

一切从最简单的一次对话开始。验证 LLM 通道能通、能多轮、能流式输出。这是整个工程的地基——后面所有机制都建立在"能和 LLM 对话"之上。

2. 核心知识点

ChatModel：langchain4j 1.20 起 ChatLanguageModel 改名为 ChatModel，chat(prompt) 一次对话。
ChatMemory：MessageWindowChatMemory.withMaxMessages(N) 维护对话窗口，多轮时自动带上历史。
StreamingChatModel：chat(prompt, StreamingResponseHandler) 流式输出，token 一个个回来。
DeepSeek 端点：OpenAI 兼容 https://api.deepseek.com/v1 + deepseek-chat，环境变量 DEEPSEEK_API_KEY。

3. 实现步骤

步骤 1：父 POM 锁定 langchain4j BOM 1.20.0，定义 LlmProvider 读环境变量建模型。
步骤 2：ChatCli——命令行循环，用户输入 → model.chat(memory) → 打印回复，memory 自动累积。
步骤 3：StreamingCli——用 StreamingChatModel，handler.onNext(token) 边收边打印。

4. 逻辑流程

用户输入 → ChatMemory 累积历史 → ChatModel.chat() → LLM → 回复 → 打印
                          ↑________________________|
（流式版：StreamingChatModel → handler.onNext(token) 逐 token 打印）

5. 关键代码

ChatModel model = OpenAiChatModel.builder()
    .baseUrl("https://api.deepseek.com/v1")
    .apiKey(System.getenv("DEEPSEEK_API_KEY"))
    .modelName("deepseek-chat").build();

ChatMemory memory = MessageWindowChatMemory.withMaxMessages(20);
String reply = model.chat(messages);

5.5 核心类详解

ChatCli（命令行入口）

作用：启动命令行对话循环，接收用户输入，调用 LLM，打印回复。

方法：
方法作用输入输出
main(String[] args)主入口，启动对话循环命令行参数无
wrapConsoleToUtf8()把控制台输出流包装成 UTF-8，避免中文乱码无无

HelloLlm（单次调用示例）

作用：最简单的 LLM 调用，只发一次消息，没有记忆。

关键代码： 
ChatModel model = ModelFactory.createDefaultChatModel();
String reply = model.chat("你好");
System.out.println(reply);

StreamingCli（流式输出示例）

作用：流式输出，LLM 一边生成一边打印，不用等完整回复。

关键流程： 1. 创建 StreamingChatModel 2. 设置流式处理器（每收到一个 token 就打印） 3. 发送消息，流式接收

🚀 初学者快速上手

前置知识：Java 基础 + 知道"API Key 是什么"。不需要懂 LLM 原理，能跑通就行。
跑起来：先设环境变量 DEEPSEEK_API_KEY，然后执行下面的运行命令，命令行里输入"你好"试试。
看到什么算成功：LLM 回复了你好的内容，多轮对话能记住你上一句说了什么。
常见问题：报 401 = API Key 没设对；报网络错误 = 检查公司代理/防火墙；中文乱码 = 先执行 chcp 65001。

6. 运行命令

mvn -q -pl s02-minimal-chat exec:java "-Dexec.mainClass=com.example.agentlab.minimalchat.ChatCli"
