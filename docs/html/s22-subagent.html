S2.2子 Agent：上下文隔离与委派

模块：subagent

1. 这个模块解决了什么

主 Agent 的上下文有限，跑久了塞满历史。子 Agent：把一件独立的事交给一个"干净上下文"的子 Agent 去做，做完只返回结果，不带回中间过程。

2. 三条路线

路线 A（task 工具）：主 Agent 调用 task 工具，子 Agent 用新对话窗口跑，只返回结果。
路线 B（Supervisor-Worker）：主管拆任务 → Worker 执行 → 聚合结果。
路线 C（langgraph4j 子图）：父图把"子图"当普通节点，子图有独立状态空间。

3. 逻辑流程

主 Agent
   ↓ task(子任务)
子 Agent（干净上下文）
   ↓
执行子任务 → 返回 Report
   ↓
主 Agent 只拿到 Report（不带中间过程）

4. 关键代码（langgraph4j 子图）

var workerGraph = new StateGraph<>(WorkState.SCHEMA, WorkState::new)
    .addNode("worker", node_async(state -> ...))
    .addEdge(START, "worker").addEdge("worker", END).compile();

var parentGraph = new StateGraph<>(WorkState.SCHEMA, WorkState::new)
    .addNode("sub", workerGraph)   // 子图当节点
    .addEdge(START, "sub").addEdge("sub", END).compile();

5.5 核心类详解

Supervisor（主管 Agent）

作用：接收任务，决定委派给哪个子 Agent。

WorkerAgent（子 Agent）

作用：在干净上下文里执行任务，不受主对话上下文污染。

方法：
方法作用输入输出
work(String task)执行任务任务描述执行结果

Aggregator（结果聚合器）

作用：把多个子 Agent 的结果聚合成最终输出。

🚀 初学者快速上手

前置知识：理解上下文窗口（token 有限）。
核心概念一句话：把一件独立的事交给"干净上下文"的子 Agent 去做，只拿结果回来。
三条路线选着学：先学路线 C（langgraph4j 子图），最直观。

5. 运行命令

mvn -q -pl s22-subagent exec:java "-Dexec.mainClass=com.example.agentlab.subagent.MainAgentApp"
核心：上下文隔离——子 Agent 的中间过程不污染主 Agent 的窗口，只返回精炼结果。
