S0.1环境搭建：从零跑起整个工程

模块：工程骨架 ｜ 前置：无（这是第 1 步）

1. 需要装什么

工具版本要求验证命令
JDK21+（推荐 21 LTS 或 25）java -version
Maven3.9+mvn -v
DeepSeek API Keyplatform.deepseek.com 申请设环境变量 DEEPSEEK_API_KEY

2. 安装步骤（Windows）

步骤 1：装 JDK 21+
    去 adoptium.net 下载 Temurin 21，装完设 JAVA_HOME。
    验证：java -version 显示 21 或更高。
步骤 2：装 Maven
    去 maven.apache.org 下载二进制包，解压后设 MAVEN_HOME 和 PATH。
    验证：mvn -v 显示版本号。
步骤 3：申请 DeepSeek API Key
    登录 platform.deepseek.com → API Keys → 创建。
    Key 格式 sk-xxxxxxxx。
步骤 4：配置 .env 文件（推荐，不用设系统环境变量）
    工程根目录已有 .env 文件，填入你的 Key：
    DEEPSEEK_API_KEY=sk-your-api-key
    程序启动时会自动读这个文件，不需要手动设系统环境变量。
想切 Ollama 本地模型？
    在 .env 里加一行：LLM_PROVIDER=ollama
    然后执行 ollama pull qwen2.5 拉模型，就能本地跑，不花一分钱。

3. 拉代码 + 一键验证

cd your-project-directory
mvn test
看到什么算成功：最后输出 BUILD SUCCESS，110 个测试全绿。说明环境 + 工程骨架都 OK。

4. 跑第一个 Demo（不需要 API Key）

mvn -q -pl s31-supervisor exec:java "-Dexec.mainClass=com.example.agentlab.supervisor.SupervisorDemo"
这是离线桩 Demo，不调真实 LLM，直接看路由轨迹。验证你本机 Maven + 编译链路通。

5. 跑第一个真实 LLM Demo

# 先确认 Key 已设
echo $env:DEEPSEEK_API_KEY   # PowerShell

mvn -q -pl s02-minimal-chat exec:java "-Dexec.mainClass=com.example.agentlab.minimalchat.ChatCli"
命令行里输入"你好"，回车，看 DeepSeek 回复。多轮对话它能记住你上一句。

🚀 初学者快速上手

6. 常见问题 FAQ

报错原因解决
Could not find the selected project in the reactor模块名改了用新目录名（如 s02-minimal-chat），看本页命令
缺少环境变量 DEEPSEEK_API_KEY.env 文件没读到确认 .env 文件在工程根目录，且 Key 已填；或加 -am 参数
BUILD FAILURE: 编码中文乱码先执行 chcp 65001，或设 MAVEN_OPTS=-Dfile.encoding=UTF-8
401 UnauthorizedAPI Key 错/没设检查 .env 文件里的 DEEPSEEK_API_KEY 是否正确
Connection refused网络不通/代理检查公司代理，或换手机热点；或切 Ollama 本地
程序包不存在Maven 没下到依赖先 mvn dependency:resolve，或删 ~/.m2/repository 重下
Exception in thread "main"主类路径错对照本页运行命令复制，别手敲
注意：JDK 版本必须 21+。17 及以下编译会失败——本工程用了虚拟线程和 record 等 21+ 特性。
