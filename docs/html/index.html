🚀 初学者快速上手（5 分钟跑起来）

环境准备（只需 3 步）

1. 装 JDK 21+ 和 Maven 3.9+
    本工程编译目标 21，本机用 JDK 25 也能跑。

2. 配置 API Key（.env 文件方式，推荐）
    工程根目录已有 .env 文件，填入你的 Key：
    DEEPSEEK_API_KEY=sk-your-api-key
    程序自动读取，不用设系统环境变量。

3. 一键构建验证
    cd your-project-directory 然后 mvn test——110 个测试全绿说明环境 OK。

第一个例子跑起来

# 跑 S0.2 最小对话（需要 API Key）
mvn -q -pl s02-minimal-chat exec:java "-Dexec.mainClass=com.example.agentlab.minimalchat.ChatCli"

# 跑 S3.1 Supervisor（离线，不需要 API Key）
mvn -q -pl s31-supervisor exec:java "-Dexec.mainClass=com.example.agentlab.supervisor.SupervisorDemo"
提示：离线 Demo（模块名带 Demo 的）不需要 API Key，直接跑。真实 LLM 调用的模块需要 .env 里配好 Key。
想切 Ollama 本地模型？在 .env 里加一行 LLM_PROVIDER=ollama，然后 ollama pull qwen2.5。
