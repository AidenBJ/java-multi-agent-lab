S2.1规划 Todo：把大任务拆成可执行清单

模块：planning

1. 这个模块解决了什么

"重构整个后端"太大了，LLM 不知道从哪下手。规划 Todo：先让 LLM 把大任务拆成小步骤清单，确认后逐步执行。

2. 核心知识点

结构化输出：让 LLM 返回 Plan（List<TodoItem>），不是自由文本。
todo_write 工具：LLM 自己调用工具写 Todo 清单，nag reminder 提醒未完成项。
确认闭环：拆完先给人确认，改完再执行。

3. 实现步骤

路线 A（工具驱动）：TodoWriteTool + TodoLoop——LLM 自己维护清单。
路线 B（结构化）：Planner → AiServices 返回 Plan，确认后 PlanExecutor 逐条执行。

4. 逻辑流程

大任务
   ↓
LLM 拆成 Plan（5 个 Todo）
   ↓
给人确认 / 修改
   ↓
逐条执行：TodoLoop 循环，todo_write 工具更新状态
   ↓
全部 done

5. 关键代码

record TodoItem(String content, TodoStatus status) {}
record Plan(List items) {}

Planner planner = AiServices.builder(Planner.class)
    .chatModel(model).build();
Plan plan = planner.plan("重构后端");

5.5 核心类详解

Planner（任务拆解器）

作用：把大任务拆解成可执行的 Todo 清单。

方法：
方法作用输入输出
plan(String task)拆解任务任务描述Todo 清单

TodoList（待办清单）

作用：存储拆解后的待办任务列表。

Executor（执行器）

作用：逐个执行 Todo 清单里的任务。

🚀 初学者快速上手

前置知识：理解结构化输出（让 LLM 返回 JSON 而不是自由文本）。
核心概念一句话：大任务先让 LLM 拆成小步骤清单，确认后逐步执行。
两条路线选着学：路线 A（工具驱动）更像 Claude Code；路线 B（结构化计划）更可控。先学 B。
