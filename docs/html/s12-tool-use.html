S1.2工具系统：让 LLM 调用外部能力

模块：tool-use

1. 这个模块解决了什么

LLM 本身只能说话，不能算、不能读文件、不能发 HTTP。工具系统让 LLM 通过 @Tool 注解声明的方法调用外部能力——算数学、读文件、调 API。

2. 核心知识点

@Tool 注解：在 Java 方法上加 @Tool("描述")，参数加 @P("参数说明")，LLM 就能看见并调用。
AiServices.tools()：把工具对象注册进 AiServices，框架自动处理 tool_use → 执行 → tool_result。
工具即 Java 方法：不需要写 JSON Schema，langchain4j 反射自动生成。

3. 实现步骤

步骤 1：CalculatorTool——加法/减法方法加 @Tool。
步骤 2：FileTools——读文件/写文件方法加 @Tool。
步骤 3：HttpTool——GET 请求方法加 @Tool。
步骤 4：ToolDemo——AiServices 注册所有工具，用户提问触发工具调用。

4. 逻辑流程

用户："1+1等于几"
   ↓
LLM 看到 CalculatorTool.add 工具 → 输出 tool_use(add, 1, 1)
   ↓
框架执行 add(1,1) → 返回 2 → 回填 tool_result
   ↓
LLM 收到结果 → 生成回复 "2"

5. 关键代码

public class CalculatorTool {
    @Tool("加法")
    public int add(@P("第一个数") int a, @P("第二个数") int b) {
        return a + b;
    }
}
var aiServices = AiServices.builder(ChatAgent.class)
    .chatModel(model)
    .tools(new CalculatorTool(), new FileTools(), new HttpTool())
    .build();

5.5 核心类详解

ToolDemo（工具 Agent 演示入口）

作用：启动带工具的 Agent，演示 LLM 自主调用工具。

方法：
方法作用输入输出
main(String[] args)主入口，构建带工具的 Agent命令行参数无

CalculatorTool（计算器工具）

作用：提供计算能力。

方法：
方法作用输入输出
add(int a, int b)加法a、b 两个整数和
subtract(int a, int b)减法a、b 两个整数差

FileTools（文件工具）

作用：提供文件读写能力。

方法：
方法作用输入输出
writeFile(String path, String content)写文件文件路径、内容成功/失败
readFile(String path)读文件文件路径文件内容

HttpTool（HTTP 工具）

作用：提供 HTTP 请求能力。

方法：
方法作用输入输出
get(String url)发送 GET 请求URL响应内容

Assistant（AiServices 接口）

作用：AiServices 用的接口，定义对话方法。

方法：
方法作用输入输出
chat(String userMessage)对话入口用户消息LLM 回复

🚀 初学者快速上手

前置知识：跑完 S1.1，理解 Agent Loop。
核心概念一句话：在 Java 方法上加 @Tool 注解，LLM 就能看见并调用这个方法。
动手试：自己加一个新工具（比如"乘法"方法），跑 ToolDemo 问 LLM "3乘4等于几"，看它会不会调你的新工具。

6. 运行命令

mvn -q -pl s12-tool-use exec:java "-Dexec.mainClass=com.example.agentlab.tooluse.ToolDemo"
关键：工具是 LLM 的"手"——没有工具的 LLM 只会说，有了工具才能干活。
